## Changes in this pass

- Patch glob/minimatch in the CMS install graph; retain strict npm audit.
- Bind browser CLI approval to the displayed account and reject cross-site starts.
- Guard owner-only policy reads and owner deletion; allow invited users to finish
  name/avatar setup without gaining account-management privileges. A new migration
  applies the self-profile rule to existing installations.
- Reject page-parent cycles, preserve omitted descendant routes during partial
  moves, retain script/style attributes on export, qualify nested page-field
  references, export explicit empty page repeaters and preserve mixed legacy arrays.
- Keep unchanged page-entry trees when unrelated page metadata changes; report
  undeclared nested page content and rebuild stored-only section groups on reimport.
- Limit concurrent import processing and snapshot multipart parsing before reading
  bodies. Staging checks developer ownership; final imports enforce the actual
  form/query/header-based update rules and existing revision/backup checks.
- Preserve failed drafts while committing unrelated queued changes; refresh publish
  artifact overlays, scope order indices to their collection and surface save/create
  failures. Fix root ordering, invalid group loading and editor-return scroll state.
- Keep failed hosted QA account cleanup in finally blocks. These scripts were only
  syntax-checked; they were not executed against a hosted environment.
- Add independent successful-run artifact verification for image publication.
  Wiring the new verifier into tag.yml is part of the permission-blocked workflow
  follow-up; the helper alone does not attest that the current workflow uses it.
- Use explicit errors for Python package integrity checks, even under optimization,
  and correct historical publication/version instructions.

## Remaining review work and qualification limits

- Workflow changes require the GitHub CLI workflow scope. Prepared changes cover
  exact-head E2E checkout, matching frozen RC.11 manifest verification and trusted
  qualification artifacts before image creation. Hosting workflow changes are
  separately prepared on #1350. No workflow push, release or deployment is implied.
- Running the native image as a non-root user requires a tested writable data path
  and existing-volume ownership plan. The current root posture is unchanged from
  the prior image; this hardening finding remains open. The local Docker client
  cannot currently validate the container, so no untested ownership change is made.
- A legacy stored-only group cannot be distinguished from a group whose last child
  was deleted before these changes without additional state. Preserve legacy data;
  track a schema/marker migration rather than silently discard it. The review
  explicitly identifies this as pre-existing follow-up behavior.
- Changed page-entry trees still use replacement semantics. Unchanged trees now
  retain their entry IDs; identity-preserving reconciliation of changed nested
  values needs a separately tested protocol and remains a follow-up.
- Fresh-machine startup retries only a confirmed port collision after retaining
  its diagnostic output; all other startup failures still fail immediately.
- Historical RC.5/RC.7 Actions artifacts expire. Preserve the exact sealed binaries
  in a durable location before expiry (recorded RC.7 expiry: 2027-01-14), with their
  existing hashes. Uploading release assets is outside this review authorization.
- Global pending CLI-login capacity is intentionally finite. Distributed unauthenticated
  traffic can exhaust any public finite capacity; removing the cap is unsafe.
  Origin checks now prevent browser-induced per-user exhaustion. Further admission
  policy needs a design decision, not unbounded pending-request storage.
- Current source changes do not alter previously published RC.3/RC.13 archives.
  New package versions/archives, manifests, native executables and coordinated
  handoff qualification are required before stable promotion. Historical passing
  qualification does not attest these new bytes. No merge/publication/deployment
  is authorized by this review pass.
